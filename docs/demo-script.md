# Two-minute demo script

- 0–20 seconds: open the overview, state the observation timestamp, and distinguish inventory from the monitored cohort.
- 20–45 seconds: filter the review queue and select one reviewed real item. State that it is a possible difference, not an accusation.
- 45–75 seconds: open the product comparison and show both exact excerpts, normalized values, capture dates, URLs, and hashes.
- 75–100 seconds: show the programme/entity rationale and append a review outcome with reviewer and note.
- 100–120 seconds: show real history if two live snapshots exist; otherwise say that only a baseline exists and use the permanently labeled synthetic fixture to demonstrate behavior.

Before export, close private tabs, confirm all values are legible, and review the MP4. If no screen recorder is available, deliver this script and mark the video outstanding.
